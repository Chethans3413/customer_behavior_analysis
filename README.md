# 🛍️ Customer Shopping Behavior Analysis

## 📌 Project Overview

This project analyzes customer shopping behavior to identify purchasing patterns, sales trends, and customer preferences. The objective is to extract meaningful insights that help businesses improve marketing strategies and decision-making.

The project demonstrates an end-to-end data analytics workflow including data cleaning, exploratory data analysis (EDA), SQL querying, and dashboard creation.

---

## 📂 Dataset

The dataset includes customer transaction details such as:

* Customer ID
* Age & Gender
* Product Category
* Purchase Amount
* Payment Method
* Location
* Purchase Date

The dataset was cleaned and processed using Python before analysis.

---

## 🛠️ Tools & Technologies

* **Python** (Pandas, NumPy, Matplotlib, Seaborn)
* **PostgreSQL** (Database management)
* **SQL** (Data querying & aggregation)
* **Power BI** (Dashboard visualization)
* **Gamma** (Report & PPT creation)
* **Jupyter Notebook**

---

## 🔎 Project Workflow

1. **Data Loading** – Imported dataset into Python using Pandas.
2. **Data Cleaning** – Handled missing values, removed duplicates, formatted data.
3. **Exploratory Data Analysis (EDA)** – Identified trends and patterns using visualizations.
4. **Database Integration** – Connected Python to PostgreSQL and executed SQL queries.
5. **Dashboard Creation** – Built interactive Power BI dashboard with KPIs and filters.
6. **Report Preparation** – Created a structured project report and presentation.
